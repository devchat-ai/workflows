### fix_issue

自动修复代码中的 lint 错误。

用法：
/fix_issue

描述：
这个命令帮助开发者自动修复代码中的 lint 错误。它使用 AI 分析选中的代码行，识别 lint 问题，并提供修复建议。然后，它会自动应用这些修复建议，并在 IDE 中显示更改。

步骤：

1. 在 IDE 中选择包含 lint 错误的代码行。
2. 运行 /fix_issue 命令。
3. 命令会自动获取选中的代码、相关的 lint 诊断信息，并调用 AI 生成修复方案。
4. AI 会提供问题解释和修复后的代码。
5. 命令会自动应用这些修复，并在 IDE 中显示更改。

注意事项：

- 确保在运行命令前已选择包含 lint 错误的代码行。
- 命令会优先处理 SonarLint 诊断的问题。
- 如果安装了 aider Python，命令会使用 aider 来执行 AI 访问和应用更改。
- 如果没有安装 aider Python，命令会使用默认实现来生成和应用修复。
- 所有的更改都会在 IDE 中以 Diff View 的形式展示，你可以在查看后决定是否接受这些更改。
