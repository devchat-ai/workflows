### commit

Automatically generate commit messages and execute Git commits.

#### Purpose

- Generate standardized commit messages
- Simplify the Git commit process
- Maintain consistency in commit history

#### Usage Method

Execute Command: `/github.commit [message]`

- message: Optional user input to assist in generating commit messages

#### Operation Process

1. Select files to commit
2. Generate commit message
3. Allow user to edit commit message
4. Execute Git commit

#### Notes

- Ensure that the necessary files have been selected for commit
- Generated commit messages may need further modification to comply with project standards
