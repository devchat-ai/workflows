### update_pr

Update an existing Pull Request.

#### Purpose

- Update PR title and description
- Reflect the latest code changes

#### Usage Method

ExecuteCommand: `/github.update_pr`

#### Operation Process

1. Get the latest PR information
2. Regenerate PR title and description
3. Allow user to edit PR content
4. Update Pull Request

#### Notes

- Ensure you have permission to update PR
- Before updating, confirm if there are new commits that need to be pushed
